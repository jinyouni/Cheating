# 📱 AI 시험문제 자동 풀이 도우미 (Exam Solver with Gemini)

스마트폰 카메라로 시험문제를 비추고 **[문제 풀기]** 버튼을 누르면, 사진을 캡처하여 **Google Gemini AI**가 문제의 **정답과 상세 풀이 해설**을 알려주는 모바일 웹 애플리케이션입니다.  
풀이가 끝나면 **[다음 문제 풀기]** 버튼 하나로 즉시 카메라 모드로 복귀하여 연속으로 여러 문제를 풀 수 있습니다.

---

## 🌟 주요 기능

1. **실시간 동영상 뷰파인더**:
   - 모바일 기기의 후면 카메라를 최적 해상도로 실시간 프리뷰합니다.
   - 문제 조준 가이드라인이 표시되어 원하는 문제만 정확히 프레임 안에 맞출 수 있습니다.
2. **원터치 캡처 & Gemini AI 풀이**:
   - [⚡ 문제 풀기] 버튼을 터치하면 그 즉시 최고 해상도로 정지 화면을 캡처합니다.
   - Google Gemini 무료 API로 전송하여 **1) 문제 내용 정리, 2) 눈에 띄는 정답, 3) 친절한 단계별 풀이 과정**을 마크다운 형태로 빠르게 생성합니다.
3. **매끄러운 다음 문제 진행**:
   - 결과 화면 하단의 [📷 다음 문제 풀기] 버튼을 터치하면 바로 카메라 모드로 돌아와 다음 문제를 촬영할 수 있습니다.
4. **안전한 API 키 관리**:
   - 발급받은 무료 Gemini API 키는 GitHub 코드에 노출되지 않고, **사용자의 휴대폰 브라우저(LocalStorage)**에만 안전하게 보관됩니다.
5. **카메라 전환**:
   - 필요에 따라 전면 / 후면 카메라를 손쉽게 전환할 수 있습니다.

## 🚀 GitHub에 올려서 휴대폰으로 테스트하는 방법

카메라 기능(`getUserMedia`)은 보안 정책상 **HTTPS** 환경에서만 동작합니다.  
**GitHub Pages**를 이용하면 별도 서버 없이 **무료 HTTPS 주소**를 즉시 만들어 휴대폰으로 접속할 수 있습니다!

### Step 1. GitHub 저장소 생성 및 코드 업로드

1. [GitHub](https://github.com/)에 로그인 후 **새 저장소(New repository)**를 생성합니다. (예: `exam-solver` 또는 `cheating`)
2. 터미널(PowerShell 또는 Bash)에서 프로젝트 폴더로 이동하여 아래 명령어를 실행합니다:

```bash
# 1. git 초기화 (이미 되어 있다면 생략)
git init

# 2. 파일 추가 및 커밋
git add index.html style.css app.js README.md .gitignore
git commit -m "feat: AI 시험문제 풀이 모바일 웹앱 구현"

# 3. GitHub 리포지토리 연결 (사용자 이름과 리포지토리명을 본인 것에 맞게 변경)
git branch -M main
git remote add origin https://github.com/<본인아이디>/<저장소이름>.git

# 4. 푸시
git push -u origin main
```

---

### Step 2. GitHub Pages 활성화 (무료 웹 호스팅)

1. GitHub의 해당 프로젝트 저장소 페이지로 들어갑니다.
2. 상단 탭에서 **`Settings` (설정)** 클릭.
3. 좌측 메뉴에서 **`Pages`** 클릭.
4. **Build and deployment** 항목의:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` 선택 / 폴더는 `/(root)` 선택
   - **`Save`** 버튼 클릭!
5. 약 1분 후 페이지를 새로고침하면 상단에 내 웹사이트 주소가 나타납니다:
   > 🌐 **Your site is live at `https://<본인아이디>.github.io/<저장소이름>/`**

---

### Step 3. 휴대폰으로 접속 및 테스트하기

1. **스마트폰(iPhone Safari 또는 Android Chrome)**에서 위 GitHub Pages 주소로 접속합니다.
2. 브라우저에서 **"카메라 권한을 허용하시겠습니까?"** 팝업이 뜨면 **[허용]**을 누릅니다.
3. 우측 상단의 **⚙️ (설정 아이콘)**을 터치하여 준비해두신 **Gemini 무료 API 키**를 붙여넣고 [저장하고 시작하기]를 누릅니다. (첫 1회만 입력하면 스마트폰에 자동 저장됩니다)
4. 시험문제를 사각형 가이드 안에 비춘 뒤, 하단의 **[⚡ 문제 풀기]** 버튼을 터치합니다!
5. 몇 초 후 Gemini가 분석한 **정답과 단계별 풀이**를 확인합니다.
6. 하단의 **[📷 다음 문제 풀기]**를 터치하여 연속으로 다음 문제를 풀어보세요!

## 💡 Gemini API 키 발급 방법 (무료)

아직 발급받지 않으셨거나 새 키가 필요하신 경우:
1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속 후 구글 계정 로그인
2. **"Create API key"** 버튼 클릭
3. 생성된 키( `AIzaSy...` 로 시작하는 문자열 )를 복사하여 앱의 설정(⚙️) 창에 등록하시면 됩니다.
